# 频谱模式 QQ 音乐歌词背景 实现计划

> **给执行者：** 使用 `03-subagent-development` skill（推荐）或 `04-plan-execution` skill 逐任务实现。
**目标：** 在频谱模式下，于频谱上部叠加一行半透明歌词，跟随 QQ 音乐逐句显示，支持「渐隐 / 几何重构 / 轮换」三种动效。
**架构：** 新增 `hubmon/lyrics.py`（`MediaWatcher` 读 SMTC + `Lyrics` 取歌词 + `LyricState` 纯逻辑定句），`render.py` 负责叠加绘制，`config.py`/`webui.py` 暴露开关，`main.py` 接线。
**技术栈：** Python 3.11、`winrt`（SMTC）、`urllib`（QQ 音乐歌词接口）、Pillow（绘制）、项目既有 `build/_pool/*.py` 断言脚本作测试。
**提交策略：** 按用户偏好，全部任务完成后**一次性提交推送**（每任务的「提交」步骤合并到最后的任务 8）。

**依据 spec：** [2026-10-16-qq-lyrics-design.md](../specs/2026-10-16-qq-lyrics-design.md)

- [ ] **步骤3: 编写最小实现**（`hubmon/lyrics.py`）
  - `_pick(cands, song_id, artist, album, duration)`: 若 `song_id` 非空，先找 `str(cand["id"])==song_id` 的候选直接返回；否则累加权重分（歌手命中 +3、专辑命中 +2、`|cand_dur - duration| <= 3s` +3，更接近再加分）取最高分；候选时长取 `cand["interval"]`（秒），缺失则跳过时长项。
  - `LYRIC_DIR = %LOCALAPPDATA%/hubmon/lyrics`，键 = `sha1(title|artist)`。
  - `_search(kw)`: POST `https://u.y.qq.com/cgi-bin/musicu.fcg`，module `music.search.SearchCgiService`，method `DoSearchForQQMusicDesktop`，取 `req.data.body.song.list` 交给 `_pick` 选 `mid`。
  - `_fetch_lyric(mid)`: 同 URL，module `music.musichallSong.PlayLyricInfo`，method `GetPlayLyricInfo`，`param={"songMID":mid,"songID":0}`；`base64.b64decode(data["lyric"])` → `parse_lrc`。
  - `_fetch_fallback(title, artist)`: 第三方 LRC 搜索接口，失败返回 `[]`。
  - `lines_for(title, artist, album="", duration=0.0, song_id="")`: 缓存命中 → 直返；否则 search→`_pick`→lyric→parse；全失败再 fallback；任何异常吞掉返回 `[]`。
  - 请求头：`User-Agent` 浏览器串 + `Referer: https://y.qq.com/`。

    - 描边：`stroke_width=1, stroke_fill=(0,0,0, int(90*opacity))`。
  - 在 `render()` 的 `if c.mode == "spectrum":` 分支内、`_spectrum_bars` 之后调用 `if c.lyrics_enable and lyric visible: self._lyric(img, d)`。
