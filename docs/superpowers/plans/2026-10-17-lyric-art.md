# 频谱歌词视觉升级 实现计划

> **给执行者：** 使用 `03-subagent-development` skill（推荐）或 `04-plan-execution` skill 逐任务实现。
**目标：** 把歌词叠加升级为艺术字体 + 逐字浮入 + 高度错落 + 可调颜色/光晕，字号 21px。
**架构：** `config.py`/`webui.py` 暴露字体/颜色/光晕三项；`render.py` 改为**逐字图层**绘制（每字一个带光晕的 RGBA 小图，按逐字进度与错落偏移粘贴）；`lyrics.py` 提供逐字时间参数并让 `LyricState` 返回每句过渡时长。
**技术栈：** Python 3.11、Pillow（`ImageFilter` 光晕）、项目既有 `build/_pool/*.py` 断言脚本。
**提交策略：** 按用户偏好，全部任务完成后**一次性提交推送**。

**依据 spec：** [2026-10-17-lyric-art-design.md](../specs/2026-10-17-lyric-art-design.md)

## 任务 3: 逐字进度与过渡时长

**文件：**
- 修改 `hubmon/lyrics.py`
- 新建 `build/_pool/lyric_word.py`

- [ ] **步骤1: 编写失败测试** `build/_pool/lyric_word.py`
  - 常量存在：`lyrics.LYRIC_STAGGER > 0`、`lyrics.LYRIC_CHAR > 0`。
  - `lyrics.word_u(t, dur, k)`：`dur` 固定时，`u_k` 随 `k` 增大而**开始更晚**（如 `u_0(0.1) > u_3(0.1)`）；`u_k` 在 `[0,1]`；`t*dur >= k*STAGGER + CHAR` 时 `u_k == 1`；`t=0` 时 `u_0 == 0`。
  - `LyricState().update(cfg, snap, lines, dt)` 返回值**含 `dur`**；对 4 字句与 12 字句，`dur` 随字数增大（`dur = CHAR + STAGGER*(n-1)`）。
  - 用 `dt` 推进到 `dur` 后 `t == 1.0`。
- [ ] **步骤2: 运行确认失败** `python build/_pool/lyric_word.py`
- [ ] **步骤3: 编写最小实现**（`lyrics.py`）
  - 用 `LYRIC_STAGGER = 0.045`、`LYRIC_CHAR = 0.22` 取代现 `LYRIC_FADE/LYRIC_GEOM`（或保留旧名作为别名，但过渡时长统一改为按字数计算）。
  - 新增模块函数 `word_u(t, dur, k)`：`return clamp((t*dur - k*LYRIC_STAGGER)/LYRIC_CHAR, 0, 1)`。
  - `LyricState.update()`：换句时按**当前句字数**算 `dur = LYRIC_CHAR + LYRIC_STAGGER*max(0, len(text)-1)`；用 `dur` 推进 `self._t`；返回 dict 增加 `"dur": dur`（换句那一帧即确定，之后不变）。
  - 其余（暂停隐藏、换歌复位、轮换）不变。
- [ ] **步骤4: 运行确认通过** `python build/_pool/lyric_word.py`，并回归 `lyric_state.py`（可能需同步其对 `t` 曲线的断言）。

## 任务 5: 渲染改造（21px / 逐字图层 / 颜色 / 光晕）

**文件：**
- 修改 `hubmon/render.py`
- 修改 `build/_pool/lyric_render.py`
- 新建 `build/_pool/lyric_glow.py`

- [ ] **步骤1: 编写失败测试**
  - 扩展 `lyric_render.py`：新边界 `y ∈ [SPEC_TOP, SPEC_TOP+28]`、`x ∈ [SPEC_X0-3, SPEC_X1+3]`；`t` 增大覆盖率不减；`visible=False` 与基线逐像素相同；三种动效各出预览图（21px）。
  - `lyric_glow.py`：同句在 `lyrics_glow=True/False` 下渲染帧**不同**；开光晕后差异像素包围盒仍落在带边界内。
- [ ] **步骤2: 运行确认失败**（两条）
- [ ] **步骤3: 编写最小实现**（`render.py`）
  - 常量改为 `LYRIC_SIZE = 21`、`LYRIC_TOP = SPEC_TOP + 3`、`LYRIC_H = 24`、`LYRIC_PAD = 3`。
  - **逐字图层**：新增 `Dashboard._lyric_cells(txt)` —— 返回 `[(char_img_rgba, dx, dy), ...]`，每字一个小 RGBA 图：
    - 用 `f.getbbox(ch)` 定该字墨框，图层尺寸 = 墨框 + `2*LYRIC_PAD`（**动态尺寸**，杜绝裁切）；
    - 图内画字形（用歌词色）+ 1px 压暗描边；若 `cfg.lyrics_glow` 开，另用 `ImageFilter.GaussianBlur(1.2)` 把字形 alpha 模糊后染成歌词色叠在字形下方；
    - 记下该字相对行绘制原点的 `dx`（累计 `f.getlength(ch)`）、`dy`（`bbox[1]`）。
    - 按 `(txt, 字体名, 颜色, 光晕)` 缓存整行的 cells。
  - 行绘制原点 `y0 = ink_mid(f, txt, LYRIC_TOP, LYRIC_TOP + LYRIC_H)`，水平居中于 `SPEC_X0..SPEC_X1`。
  - 新增 `Dashboard._lyric_v2(img)`（替换 `_lyric` 的分支逻辑）：
    - 取 `LyricState.update` 给出的 `text/prev/t/dur/effect/visible` 与 `cfg`；
    - **逐字浮入**：对每个字 `k`，`u = lyrics.word_u(t, dur, k)`；alpha = `opacity*255*u`；y = `y0 + dy + _seat(txt,k) + (1-u)*3`；paste；
    - **几何重构**：在 `u` 之上再叠加散位——把每个字的图层按 3 条竖块切开，各块位移 `_jitter(txt,k,i) * (1-u)²`；
    - **渐隐/轮换**：沿用同一逐字机制，仅不做竖块切分；
    - 旧句 `prev` 整体按其自身 alpha 淡出（或同样逐字反向），保持简洁。
  - `render()` 仍只在 `mode=="spectrum"` 且 `cfg.lyrics_enable and lyric_visible` 时调用。
  - **不要**动 `_look_sig()`。
- [ ] **步骤4: 运行确认通过** + 目视预览图（幼圆/细黑各一张，确认字形完整、逐字可见、错落自然）。
