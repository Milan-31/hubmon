## 1. 排期与边界

两条工作流，**严格串行**：

| 顺序 | 工作流 | 入口条件 | 出口条件 |
|---|---|---|---|
| **A（先）** | 音频频谱模式（已选 ①④⑤ / 24 段对数 / `sounddevice` 回环 / 全屏接管模式 / 瓦数单开关） | 你确认 A 的 5 段设计 + 预览 → 写频谱 spec | 实现完成、实机验证、提交推送 |

边界规则（防止两份设计互相污染）：

1. B 的改动**不得搭乘 A 的提交**。顶栏、卡片几何、涂层、字体的改动一律属于 B。
2. 若 A 顺带需要某个改动（例如频谱需要顶栏让出高度），该改动**先在 A 里以最小可用形态落地**，B 在此基础上继续重做，不回滚。
3. `_look_sig()` 与静态烘焙的改动最容易引发"重烘焙闸门漏字段"这类隐蔽 bug —— 两份 spec 各自把涉及的字段列全，互不引用。
4. 两份 spec 各自独立过审、独立验收；B 不假设 A 的实现细节。

## 2. 背景与目标

你这次的原话是「更现代化和美观、具有细节的风格，可以重构整体风格」。当前壳体的状态是：

- **`glass` 面**：圆角 16px，观感主要由**模糊泛光**撑起来 —— 背景模糊后塞进卡片、再叠白色玻璃渐变、顶面高光、两层边缘层、投影。
- **`quartz` 面**：直角，机加工表壳语言 —— 表盘（背景去色后与枪灰混合、压暗）、每张卡片一圈铬合金倒角、四角一字螺钉、顶栏金属铭牌、七段数码读数。

问题在于：**两面的"精致"程度不对等**。quartz 有结构（倒角、螺钉、铭牌、刻度语言），glass 的精致几乎全靠模糊泛光这一种手法；同时两面对"仪表感"的表达方式也不统一 —— 一个靠金属，一个靠光。除此之外，面板本身**缺少刻度语言**：没有基线、没有量程刻度、没有分隔结构，数值是浮在色块上的。

目标（可验证）：

1. 两面**同属一台仪器**：共用一套结构语汇（基线导轨、量程刻度、分隔线、刻蚀微标签），差别只在材质（铬 vs 玻璃）。
2. glass 面的精致**从"光"改成"结构"**：用分层边缘（内亮圈 + 内阴影 + 顶部高光）替代单一模糊泛光，不再依赖背景模糊强度。
3. 新增细节**全部落在静态烘焙或量化里**：任何持续重绘的新装饰都不接受。
4. 可读性不降：正文与数字的对比度、字号不得低于当前基线。

## 3. 硬约束（不可协商）

- **画布** 320×170，RGB565 大端；数值量化在小尺寸下会吃掉细笔画。
- **局部刷新**：脏矩形粒度 16×10 tile；链路实测上限约 **800 KiB/s**，当前仪表盘约 150 KiB/s @ 49–55 fps。新增装饰若每帧重绘，等于直接抢带宽。
- **两行内容高度固定**：顶栏 `Geo(8,4,304,16)`；大卡 `Geo(8,24,150,big_h)` 与 `Geo(162,24,150,big_h)`，`big_h` ＝ 78（显示底部卡时）或 140；底部卡最多 3 张，`y=106, h=58`。总高只剩 170px，**任何新增结构必须从现有留白里挤，不能加高**。
- **两面必须保持可区分**（此前你明确要求过区分度），不能合并成一个面。
- **配置必须回环**：新增项要能通过 `Config` + `update_from()` 白名单 + 面板 SCHEMA 三处齐全；参与静态烘焙的字段必须进 `_look_sig()`。
- **文字**：正文 ≥ 现有同级字号；灰阶不得压到与背景融合（RGB565 会进一步压暗低对比笔画）。

## 5. 方向选项

### 方向 1 —— 合并为单一仪表语言
把 `glass` / `quartz` 塌缩成一台"台面仪器"：默认机加工表壳，`style` 开关只切换**读数语汇**（矢量槽轮 vs 七段数码），家具不再整套换。

- **利**：身份最强、代码最少；频谱那套"母带仪表"语言可以原样延伸过来。
- **弊**：**与你此前明确要求的"两个风格要有区分度"直接冲突**。
- 结论：**不建议**。

### 方向 2 —— 现有语言上加结构（推荐）
保留两面，各自把"精致"升级为结构，并给双面加上共用的刻度语汇：

- **`quartz` 加深**：表壳外圈加**倒角层次**（外圈亮边 / 内圈暗槽），铭牌做**内凹窗口**（文字落在一个真正凹进去的凹槽里），螺钉增加**槽口朝向**，卡片上缘加**刻蚀量程刻度**。
- **`glass` 换骨**：把"模糊泛光"换成**分层边缘** —— 内亮圈（1px 高光）+ 内阴影（底面压暗）+ 顶部细高光，再加一层极淡的竖直渐变；模糊只留作背景氛围，不再充当卡片结构。
- **双面共用**：每张卡片右侧一条**量程刻度**（0/50/100，发丝刻度 + 微标签）；标签行与数值区之间加一条**发丝分隔**；顶栏左右内容之间加**居中分隔点**。
- **利**：正面回应"现代化 + 细节"；两面区分度保住；**所有新增都是静态烘焙**（刻度、分隔、倒角都不随数据变化）。
- **弊**：`glass` 换骨后观感和现在差别明显，需要出图确认；quartz 的倒角层次要注意不要吃掉 4px 内缩。
- 结论：**推荐**。

### 方向 3 —— 编辑式极简
拆掉卡片底色，只留排版与发丝分隔，液面改成细横条量尺。

- **利**：可读性最高、带宽最省、非常"现代排版"。
- **弊**：丢掉器物的体量感 —— 而你此前一路都在往"空腔 / 金属 / 液面"这个方向走（新拟物、水池、机壳），方向 3 等于把这条路砍掉。
- 结论：**备选，但不推荐**。

## 6. 选定方向（暂定方向 2）的具体设计

**共享刻度语汇（两面一致，也是和频谱语言对接的接口）**

- 卡片右侧竖向量程刻度：0 / 50 / 100 三条发丝刻度线 + 微标签，刻度长 3px、标签 8px 字号。
- 标签行与数值区之间 1px 发丝分隔，左右内缩到 `PAD`。
- 顶栏在中段网速两侧各一个 2px 分隔点，把"主机 / 网速 / 时钟"三块视觉上分组。
- 全部烘焙进静态层；只有数值与液面在动。

**`quartz` 升级**

- 壳体三层次：外圈 `METAL_HI` 亮边（1px）→ 中段 `METAL_LO` → 内圈暗槽（1px `TEXT_SHADOW`），把现在的单层渐变改成有厚度的倒角。
- 铭牌凹陷：文字带 1px 暗描边落在凹槽里，窗口四角做 1px 内圆角。
- 螺钉槽口按机加工习惯统一朝向（不再随机）。
- 刻度用**刻蚀**表现：暗刻线 + 下方 1px 亮线，像真实蚀刻而非印刷。

**`glass` 换骨**

- 卡片结构改为：内亮圈（`rgba(255,255,255,.10)` 1px）→ 内阴影（底部 −18 亮度）→ 顶部 1px 高光 → 极淡竖直渐变（顶 7 / 底 0）。
- 保留背景模糊只作**背景氛围**（模糊度仍由「背景模糊」配置控制），卡片内部不再依赖它。
- 投影收窄：`-6px` 偏移、更大模糊半径，避免现在的"厚塑料"感。

**不做的事（明确排除）**

- 不改卡片几何与位置（除刻度占用现有留白）。
- 不加新的动态装饰（不引入扫光、律动、粒子 —— 这些此前已被明确移除并写入项目约定）。
- 不改配色体系与指标色系（CPU 青 / GPU 紫 / 内存青绿 / 功率渐变）。
- 不改频谱功能本身的实现。

## 8. 验收标准

1. **可读性不回退**：正文、数字、单位的最小字号与对比度不低于当前基线；RGB565 量化后仍清晰。
2. **带宽不回退**：`style_link.py` 每帧脏区不高于当前（glass 约 15.0 KiB / quartz 约 16.7 KiB）。
3. **耗时在预算内**：`style_cost.py` 两面均 < 16.7 ms/帧（60fps 预算）。
4. **区分度保住**：两面并排肉眼可辨（出图核对）。
5. **烘焙闸门正确**：任何影响静态层的配置改动都能正确触发重烘焙，且不因漏字段出现残影。
6. **回环正确**：新增配置项在面板 → `Config` → `update_from()` 三处齐全，落盘可回读。
